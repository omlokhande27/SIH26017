# DELIBERATELY NOT INSTALLED
#
#   xgboost, lightgbm  A gradient-booster cannot extract signal this dataset
#                      does not contain. With 22 distinct feature vectors and
#                      83% of rows sharing one, it would memorise the 21
#                      singletons and report a flattering in-sample R² that
#                      means nothing. scikit-learn's RandomForest already
#                      demonstrates that honestly, at a fraction of the
#                      install weight. Revisit when the data supports it.
#
#   shap               SHAP explains a model's contribution to its own output.
#                      Explaining a model that does not beat a median baseline
#                      would dress up noise as insight. The rule engine
#                      provides real, auditable explanations instead — it is
#                      the primary signal by design. Revisit in Phase 5 if the
#                      ML model ever earns its place.
